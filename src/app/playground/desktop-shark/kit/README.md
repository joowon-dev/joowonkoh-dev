# kit — desktop-shark 게임 코드 사본

`game/` 과 `render/` 는 `~/desktop-app/desktop-shark/src/` 에서 **그대로 복사**했다
(desktop-shark `v1.0.4`). 한 줄도 고치지 않았다.

페이지 맨 위의 데모와 도감 그림은 앱과 **같은 엔진·같은 그림 함수**로 돈다 — 데모가 앱과
다르면 데모가 아니다(치이카와 페이지의 `kit/` 과 같은 규칙).
고칠 때는 desktop-shark 쪽을 먼저 고치고 여기로 다시 복사한다.

`net/`(랭킹 서버)은 가져오지 않았다. 데모에서 준 밥은 어디에도 올라가지 않는다.
