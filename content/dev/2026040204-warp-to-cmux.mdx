## 터미널이 왜 중요한가

Claude Code는 터미널에서 돌아간다. 에디터가 아니라 CLI 기반이라서, 어떤 터미널을 쓰느냐에 따라 작업 경험이 크게 달라진다. 코드를 짜는 동안 Claude가 파일을 수정하고, 빌드를 돌리고, 커밋까지 하는데 그 과정을 얼마나 편하게 볼 수 있느냐가 핵심이다.

나는 처음에 Warp를 썼다가 지금은 cmux로 완전히 옮겼다. 그 과정에서 느낀 점을 정리한다.

## Warp를 쓰면서 좋았던 점

Warp는 "모던 터미널"이라는 컨셉에 맞게 잘 만들어진 앱이다.

- **블록 기반 인터페이스.** 명령어와 출력이 블록 단위로 구분되어서 스크롤할 때 보기 편하다.
- **AI 자동완성.** 명령어를 치다가 자연어로 질문할 수 있다.
- **크로스 플랫폼.** macOS, Linux, Windows 전부 지원한다.
- **깔끔한 UI.** 기존 터미널 앱들과 비교하면 확실히 예쁘다.

처음 Claude Code를 쓸 때도 Warp에서 돌렸다. `/terminal-setup` 명령으로 Shift+Enter 설정하면 줄바꿈도 잘 되고, 기본적인 사용에는 문제가 없었다.

## Warp에서 아쉬웠던 점

문제는 Claude Code를 "진지하게" 쓰기 시작하면서 나타났다.

- **필수 로그인.** 터미널을 열려면 계정 로그인이 필요하다. 오프라인이나 네트워크 불안정할 때 불편하다.
- **tmux 호환 문제.** Claude Code를 여러 개 병렬로 돌리려면 tmux가 필요한데, Warp에서 tmux를 쓰면 화면이 깨지거나 불안정한 경우가 있었다.
- **알림이 약하다.** Claude Code가 작업을 끝내면 알림을 받고 싶은데, Warp는 별도 플러그인을 설치해야 했고 그마저도 불안정했다.
- **독자적 워크플로우.** Warp만의 방식이 강해서 기존 터미널 습관과 충돌하는 부분이 있었다.

특히 이 블로그를 만들면서 Claude Code를 하루 종일 돌렸는데, 작업이 끝났는지 확인하려고 매번 터미널을 들여다봐야 했다. 그게 생각보다 피로했다.

## cmux를 발견하다

cmux는 2026년 2월에 나온 macOS 전용 터미널이다. "AI 코딩 에이전트를 위한 터미널"이라는 컨셉으로 만들어졌다.

처음에는 "또 새로운 터미널이 나왔네" 정도로 지나쳤는데, Claude Code 커뮤니티에서 계속 언급되길래 한번 써봤다. 그리고 바로 전환했다.

## cmux의 결정적 차이

### 알림이 자동으로 온다

이게 제일 컸다. Claude Code가 작업을 끝내면 해당 패인에 파란색 링이 뜨고, macOS 알림도 자동으로 온다. 별도 설정 없이 바로 작동한다. 다른 작업을 하다가도 알림을 보고 돌아오면 된다.

### tmux 없이 분할이 된다

Cmd+D로 수직 분할, Cmd+Shift+D로 수평 분할. 사이드바에 각 패인의 git 브랜치와 작업 디렉토리가 표시되어서 여러 프로젝트를 동시에 돌려도 헷갈리지 않는다.

### claude-teams가 한 줄로 된다

Claude Code의 팀메이트 모드를 쓰려면 원래 tmux 세팅이 필요한데, cmux에서는 `cmux claude-teams` 한 줄이면 끝난다. 팀메이트가 네이티브 분할 패인으로 생성된다.

### 브라우저가 내장되어 있다

개발 서버를 띄우면 옆 패인에서 바로 확인할 수 있다. 브라우저를 따로 왔다갔다 하지 않아도 된다.

### 로그인이 필요 없다

설치하고 바로 쓰면 된다. 무료이고 오픈소스(GPL-3.0)다.

## 아쉬운 점도 있다

- **macOS 전용이다.** 윈도우나 리눅스에서는 쓸 수 없다.
- **세션 복원 한계.** 레이아웃은 복원되지만 실행 중이던 Claude Code 프로세스는 복원되지 않는다.
- **아직 초기 프로젝트다.** Warp에 비하면 기능이 적고 커뮤니티도 작다.

맥을 쓰는 사람에게는 문제가 없지만, 크로스 플랫폼이 중요하다면 Warp가 여전히 좋은 선택이다.

## 누구에게 뭘 추천하는가

**cmux를 추천하는 경우:**
- macOS를 쓰고 Claude Code를 메인으로 쓰는 사람
- 알림이 중요한 사람 (멀티태스킹하면서 에이전트 돌리는 경우)
- tmux 설정 없이 깔끔하게 병렬 작업하고 싶은 사람

**Warp를 추천하는 경우:**
- 윈도우나 리눅스도 써야 하는 사람
- Claude Code보다 Warp 자체 AI를 메인으로 쓰는 사람
- 모던 터미널 UI를 좋아하는 사람

나는 맥에서 Claude Code를 하루 종일 쓰는 사람이라 cmux가 딱 맞았다. 특히 알림 하나만으로도 전환할 가치가 있었다. "Claude Code가 끝났는지 확인하려고 터미널을 들여다보는" 그 피로가 사라진 게 가장 크다.
