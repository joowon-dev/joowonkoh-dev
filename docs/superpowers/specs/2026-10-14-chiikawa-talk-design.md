# 먼작귀 통역기 (`/playground/chiikawa-talk`) — 설계

## 무엇을, 왜

한글로 말을 적으면 먼작귀(치이카와) 친구들 말로 통역해 주는 놀이 페이지.
규칙 기반이라 서버·API 키·비용이 없고, 같은 문장은 늘 같은 통역이 나온다.
**글자만** 낸다 — 음성은 이번 범위가 아니다(나중에 붙이기 쉽게 결과를 토막 배열로 낸다).

## 분위기

최대한 귀엽게. 치이카와 세계 느낌의 파스텔 톤 —
연분홍·하늘·크림 배경, 둥근 손글씨풍 폰트(Google Fonts), 두꺼운 둥근 테두리 말풍선,
작은 별·꽃·풀 장식, 버튼은 말랑하게 눌리는 애니메이션.
친구 그림은 이미 쓰고 있는 `desktop-chiikawa` 스프라이트를 크게 쓴다(아래).
공식 사이트의 이미지를 긁어 오거나 공식 사이트처럼 보이게 꾸미지는 않는다 —
팬이 만든 놀이 페이지로 보이게(하단에 「팬 메이드, 공식 아님」 한 줄).

## 화면

- 위: 한글 입력창 + 「통역하기」 버튼.
- 캐릭터 고르기: **치이카와 / 하치와레 / 우사기** 세 탭. 고르면 바로 다시 통역한다.
- 아래: 고른 친구의 말풍선. 토막이 하나씩 톡톡 나타나고(타자 효과), 밑에 작은 글씨로 원문.
- 「복사」 버튼으로 통역 결과를 클립보드에.
- 캐릭터 그림은 `desktop-chiikawa/sprites.ts` 의 `loadSprites()` 를 그대로 쓴다
  (비공개 버킷, `CHII-SITE` 코드). 못 받으면 이름표만 보인다. 그림은 저장소에 넣지 않는다.

## 통역 엔진 — `translate.ts` (순수 함수)

```ts
type Character = "chiikawa" | "hachiware" | "usagi";
type Mood = "joy" | "sad" | "scared" | "hungry" | "surprised" | "angry" | "question" | "plain";
translate(text: string, who: Character): { sentences: { tokens: string[]; mood: Mood }[] }
```

1. **문장 나누기** — `. ! ? ~ …` 과 줄바꿈 기준. 빈 문장은 버린다.
2. **감정 읽기** — 문장마다 하나. 키워드 사전(`lexicon.ts`)이 먼저, 없으면 기호로:
   `ㅠ/ㅜ/슬퍼/울` → sad, `무서/어떡해` → scared, `배고/먹/맛있` → hungry,
   `좋아/신나/ㅋㅋ/최고` → joy, `헉/대박/진짜?` → surprised, `짜증/화나/싫어` → angry,
   `?` → question, 그 밖 → plain. 여러 개 걸리면 사전에 적힌 우선순위대로.
3. **시드** — 문장 원문을 해시해 시드로 쓰는 작은 RNG. 같은 입력·같은 캐릭터면 같은 결과.
4. **캐릭터별 만들기**
   - **치이카와 / 우사기 — 소리로 바꾼다.** `캐릭터 × 감정` 사전에서 소리를 골라 이어 붙인다.
     토막 개수는 원문 글자 수에 비례(1~6개). 예:
     치이카와 sad `와…` `흐에에…` `아…`, joy `와아!` `야다…!`(기쁨의 떨림),
     우사기 joy `야하!` `우라!` `푸루루루`, angry `우라아앗!!`, question `하아?`.
   - **하치와레 — 뜻은 그대로, 말투만 바꾼다.** 원문을 남기고
     어미를 바꾸고(`~요/~다` → `~야!`, `~어` → `~어~`), 감정에 맞는 감탄사를 앞뒤에 붙인다
     (`헤헤`, `와아~`, `어떻게든 되라─!`, `괜찮아 괜찮아`). 바꿀 어미가 없으면 감탄사만 붙인다.
5. **문장부호 살리기** — 원문의 `!!`, `?`, `…` 를 마지막 토막에 그대로 붙인다.

## 파일

```
src/app/playground/chiikawa-talk/
  page.tsx          메타데이터 + runtime = "edge"
  Translator.tsx    입력·탭·말풍선·복사 (client)
  translate.ts      엔진
  lexicon.ts        감정 키워드 + 캐릭터별 소리/말투 사전
  translate.test.ts
```
플레이그라운드 목록(`src/app/playground/page.tsx`)에 카드 한 장 추가.

## 테스트 (vitest)

- 같은 입력 → 같은 출력(결정적).
- 감정 분류: 대표 문장마다 기대 감정.
- 빈 입력·공백·기호만 → 빈 결과, 터지지 않음.
- 치이카와/우사기 토막은 모두 각자 사전 안의 소리.
- 하치와레 결과에는 원문 낱말이 남아 있다.

## 범위 밖

음성, AI 통역, 거꾸로 통역(먼작귀 → 한글), 공유 링크.
원작 음성·이미지 파일은 쓰지 않는다.

## 배포 확인

`npm run pages:build` 로 Cloudflare 와 같은 빌드를 돌려 본다(새 라우트라 edge 런타임 필수).
