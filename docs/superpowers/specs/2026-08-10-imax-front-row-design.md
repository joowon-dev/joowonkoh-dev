# 아이맥스 1열 — 설계

/ 2026-08-10

웹캠 영상을 IMAX 스크린에 걸고, 그 상영관 **1열 좌석에서 올려다본 시점**으로
실시간 렌더한다. "오디세이 아이맥스 1열" 밈을 그대로 체험하게 만드는 것이 목적이다.

## 무엇을 만드는가

- 경로: `/playground/imax-front-row`, 제목 "아이맥스 1열"
- 실시간 화면만. 촬영·녹화·저장·전송 없음. 영상은 브라우저 밖으로 나가지 않는다.
- 좌석은 1열 정중앙 고정. 대신 **고개는 돌린다**(드래그 / 자이로).
- 얼굴만 잘라내지 않는다. 웹캠 프레임 전체를 1.43:1로 센터 크롭해 스크린에 건다.
  방 전체가 IMAX에 걸리는 편이 더 웃기고, 얼굴 검출 의존성이 통째로 사라진다.

## 왜 WebGL인가

왜곡을 흉내내지 않고 **실제 기하로 만든다.** 곡면 스크린을 3D 공간에 세우고
1열 눈높이에 카메라를 두면, 사다리꼴 왜곡·좌우 감김·아래는 거대하고 위는
좁아지는 원근이 전부 투영의 결과로 따라 나온다.

대안이었던 Canvas 2D 가로 스트립은 세로 사다리꼴만 되고 좌우 곡률이 안 나온다.
CSS `rotateX`는 곡률이 0이다. 1열의 정체가 "화면이 나를 감싼다"인데
그걸 못 만들면 만들 이유가 없다.

## 극장 수치

실제 IMAX GT 규격에서 가져왔다.

| 항목 | 값 |
| --- | --- |
| 스크린 | 폭 22m(호 길이) × 높이 16m, 1.43:1 |
| 하단 모서리 | 바닥에서 1.0m |
| 수평 곡률 반경 | 26m, 관객 쪽으로 오목 |
| 상단 기울기 | 3°, 위쪽이 관객 쪽으로 |
| 눈 위치 | 스크린 중앙 평면에서 6.0m, 높이 1.4m |
| 시야각 | 세로 100°, 기본 앙각 +33° |

여기서 따라 나오는 것:

- 스크린 꼭대기를 보려면 **위로 71.7°**를 올려다봐야 한다. 목이 꺾이는 각도.
- 스크린 좌우 끝은 시선 중심에서 ±75°. 가로 화각(16:9에서 약 129°)을 넘어
  **프레임 밖으로 넘친다.** "한눈에 안 들어온다"가 1열의 정체다.
- 세로로는 -5°부터 +71.7°까지 76°를 차지한다. 화각 100° 안에 겨우 들어온다.

## 모듈

```
src/app/playground/imax-front-row/
  page.tsx          메타데이터. 정적 프리렌더라 runtime 표기 없음
  ImaxFrontRow.tsx  웹캠 취득, rAF 루프, 드래그·자이로, 권한 게이트
  screen.ts       ★ 곡면 스크린 기하: 표면 위 점, 메시 생성, 센터 크롭 UV
  seat.ts         ★ 좌석 시점: 뷰·투영 행렬, 시선 클램프, 앙각 계산
  ambience.ts     ★ 상영관 분위기: 게이트 위블, 플리커, 스크린 스필 색
  gl.ts             셰이더 컴파일·프로그램·텍스처 얇은 래퍼
  *.test.ts       ★ 세 모듈
```

★ 순수 함수. 이 프로젝트에서 실제로 깨지는 건 기하라서, 테스트도 "돌아간다"가
아니라 **1열이 맞는지**를 확인한다.

- 스크린 꼭대기 앙각이 65°를 넘는다 — 안 넘으면 1열이 아니다
- 투영된 스크린 하단 폭 > 상단 폭 — 사다리꼴이 뒤집히지 않았는지
- 좌우 끝 정점이 중앙보다 관객 쪽에 있다 — 곡률 방향
- 모든 정점이 카메라 앞에 있다 — 90°를 넘으면 투영이 발산한다
- 시선 클램프가 스크린 밖으로 안 나간다
- 크롭 UV가 원본 비율과 무관하게 1.43:1을 유지한다

## 렌더 패스

캔버스 하나에 세 번 그린다. DOM 오버레이를 섞지 않는 이유는 빛 번짐이 따로 놀아서다.

1. **상영관** — 전체화면 쿼드. 카메라 광선 방향으로 바닥·무대턱·스피커 그릴·
   측벽 패널·천장을 해석적으로 칠한다. 전부 스크린 스필 색으로 물든다.
   EXIT 초록 등 두 개도 여기서 광선 방향으로 얹는다.
2. **스크린** — 64×48 곡면 메시에 웹캠 텍스처. 셀피처럼 좌우 반전.
   게이트 위블은 카메라가 아니라 **스크린 모델 행렬**에 건다. 실제 영사기가
   그렇게 흔들린다.
3. **필름** — 전체화면 오버레이. 그레인, 비네트, 밝기 플리커.

스크린 스필 색은 8×8로 줄인 웹캠 프레임의 평균색이다. 매 프레임 하지 않고
6프레임에 한 번 갱신한다.

## 권한과 실패

`gaebari-glare`의 흐름을 따른다. 시작 버튼 → `getUserMedia` → 거부·미지원이면
전용 안내 패널. WebGL2를 못 얻는 경우도 같은 자리에서 안내한다.
페이지를 떠나면 트랙을 확실히 끈다.
